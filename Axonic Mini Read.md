Axonic Mini UI Library

Axonic Mini UI Library is a lightweight and easy-to-use Roblox Lua interface library created by Kenniel, also known as Axonic Hub.

The library is designed to make building clean Roblox interfaces quick and simple. It includes commonly used UI elements, built-in theming, a key system, customizable links, and an easy API for creating controls.

Features
🌙 Dark Theme
🔑 Built-in Key System
🔗 Get Key, Discord & Lifetime Key links
🔘 Toggles
⌨️ Text Inputs
🔢 Numbers-only Inputs
🖱️ Buttons
📋 Dropdown Menus
🎚️ Sliders
⌨️ Custom Keybinds
➖ Dividers / Sections
🔽 Minimize & Restore UI
📝 Custom Footer
⚡ Simple callback-based API
📦 Lightweight and easy to configure
